# Bioreactor dosimetry example

This directory will contain the approved example data and analysis materials for the bioreactor dosimetry application.

# Bioreactor tube dosimetry

The planar scanning workflow was applied to evaluate two different serpentine glass-tube configurations for a bioreactor using two 222 nm excimer lamps. Both tubes had a 4 mm outer diameter but followed different paths across the irradiated area.

A 220 × 160 mm irradiance field was measured over the 200–240 nm band at 2 × 2 mm resolution and a 10 mm standoff. The measured field was then registered to the CAD-defined centreline of each tube to estimate the irradiance experienced along its path.

The first tube had an evaluated path length of 1366 mm and a mean centreline irradiance of 686 µW/cm². The second tube had an evaluated path length of 1254 mm and a mean centreline irradiance of 780 µW/cm². This application demonstrates how the same planar measurement can be combined with different tube geometries to produce design-specific optical-dose information.
